KanaDance （ローカル版）

■ 使い方

  「KanaDance を起動.bat」をダブルクリックするだけ。
  黒い画面が出たあと、ブラウザが自動で開きます。
  カメラの使用を聞かれたら「許可」を選んでください。

  終わるときは、黒い画面で Ctrl+C を押すか、画面を閉じてください。

■ 必要なもの

  なし。Python もこのフォルダの python\ に入っています。
  インストールも管理者権限も要りません。
  ネットにつながっていなくても動きます。

  ※ IronPython が入っている PC でも問題ありません。
     あれは Python 2 系で使えないため、自動で避けて
     同梱のほうを使います。

■ 画面と操作

  画面は窓の幅いっぱいに広がります。F11 で全画面にすると展示の見た目になります。

    右上の青い丸       … シャッター。いま出ている字を下の帯に記録する
                         （Space キー・Enter キーでも切れます）
    右上の小さな「調整」 … 調整パネルを開く（濃さ・一致しやすさ・体型合わせ・
                         登録モードなど）。値は次に開いたときも残ります

  ※ 調整の「記録の書き出し」を入れると、撮るたびに PNG が
     その PC のダウンロードフォルダに保存されます。本番は「しない」に。

■ 登録したポーズの行き先

  data/poses.json に貯まります。USB の中なので、別の PC に差しても
  そのまま使えます。中身はただのテキストなので、開いて確認もできます。
  同じ字を何度も登録すると、全部が判定の手本になります。

  ※ 字ごとの線と、作った時点の登録は Supabase から写したものです。
     線を変えたいときは Mac 側で身振りスケッチを直し、
     ./build.sh --full --refresh-poses で作り直してください。

  ※ USB が書き込み禁止だと登録できません（判別は動きます）。

■ うまくいかないとき

  ・ブラウザが開かない
      黒い画面に出ている http://localhost:8000/ を
      手で入力して開いてください。

  ・「ポート 8000〜8009 を使えません」と出る
      8000 が使われていると 8001、8002…と自動でずらしますが、
      全部ふさがっていると出ます。黒い画面を閉じて、少し待ってから
      もう一度実行してください。KanaDance を2つ同時に起動していないかも確認を。

  ・カメラが映らない
      ブラウザのアドレス欄の左にあるカメラのマークから、
      許可に変えてください。ほかのアプリがカメラを使っていると
      映らないことがあります。

  ・画面は出るが線が出ない
      判別に使えるのは、作ったときに入れた字と線の一覧
      （app/pose-sets/kana-lines.json）に載っていて、
      ポーズも登録されている字だけです。調整パネルの「判別」の下に
      何字使えるかが出ます。

■ もし「姿勢推定モデルを読み込めません」と出たら

  このフォルダは --full（削らない版）で作ってあり、古い PC 向けの
  予備も入っています。それでも出るときは、ブラウザを Chrome か
  Edge の新しいものにしてください。

■ 分けてコピーしても大丈夫です

  USB から PC の中へ移しても、フォルダを何回かに分けてコピーしても
  問題ありません。置き場所はどこでも構いません。

  最後に、次の5つが横並びに揃っていればOKです。

    KanaDance を起動.bat   server.py   python   app   data

  ※ もしコピーし残しがあると、起動時に「ファイルが揃っていません」と
     足りないものの名前が出ます。その時は入れ直してください。

  ※ PC の中で動かすと、登録したポーズはその PC の data/poses.json に
     貯まります。USB へ戻したいときはそのファイルだけコピーしてください。

■ 中身

  KanaDance を起動.bat … これを実行する
  server.py            … 配信と保存をするだけの小さなサーバ
  python/              … 同梱の Python（python.org の埋め込み版）
  app/                 … 本体（vendor/ に MediaPipe を同梱）
  data/poses.json      … 登録したポーズ
  manifest.json        … コピー漏れを見つけるための一覧
