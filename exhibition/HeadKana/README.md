# HeadKana — 展示版

`HeadKana-gestures/site-lcd/dist`（2026-11-01 時点の最新 Web 版）をそのまま写したもの。
元のサイトはドメイン直下で配る前提で `/app.js` のような絶対パスだったので、
Pages のサブパスで動くよう `index.html` `output.html` `dial-custom.css` `dial-custom.js` `app.js` のパスを相対に直した。
そのあと展示用に足したのは、文字だけのページの白黒反転、PCのフォントの切り替えの高速化、商用書体を画像にして使う仕組み（下）。

## PCのフォントの切り替えを速くする

Mac の和文書体は1ウェイト 5〜20MB あり、切り替えるたびに読み込むと遅かった（13MB の筑紫Aオールド明朝で約225ms）。
いまは次のようにしている。

- **使う字だけに削る。** `font-subset.js` が、読み込んだ書体を英数・かな・記号（U+0020–007E、2010–2027、3000–30FF、FF01–FF5E と記号の候補）だけに削る。
  13MB が約170KB になり、読み込みは約40ms。削るのは harfbuzz の hb-subset（`vendor/harfbuzz-subset.wasm`、harfbuzzjs 1.6.3、MIT）。削れない書体は元のまま使う
- **裏で先に読み込む。** フォントを読み込んだあと、右ダイヤルの候補にある書体を、いまのウェイトに近いものから順に全部読み込んでおく。読み込み済みなら切り替えは一瞬
- **2回目からは自動で読む。** Chrome でローカルフォントを一度許可していれば、ページを開くたびにボタンを押さなくても読み込む（ダイヤルの候補は保存した設定のまま）
- **文字だけのタブへは1回だけ送る。** 書体データは書体とウェイトごとに1回だけ送る。新しいタブが開いたときは送り直す

漢字など、削った範囲にない字は標準の書体で出る。

- 入力画面：`index.html` ／ 文字だけの別タブ：`output.html`
- ファームウェア（RP2040-Zero ダイヤル・CoreS3）：`firmware/`。仕様と配線は `firmware/README.md`、BLE は `firmware/BLE_PROTOCOL.md`

## 商用書体をラズパイで使う

ラズパイには Mac の書体（モリサワ・写研・フォントワークス）が入らないので、**Mac で字を PNG に焼いて持っていく**。
焼いた書体は**文字だけのページだけ**が画像で描く。操作画面では書体名に「（画像）」が付き、字はゴシックで代わりに出る。

SVG やフォントの切り出しにしないのは、字の輪郭データを契約外の機械に置くことになるから。
LETS は画像化したものをアプリで使うことを許しているが、輪郭やフォントファイルの組み込みは別契約だった。
モリサワ（写研を含む）の扱いは展示前に規約で確かめる。

### 焼く（Mac の Chrome）

1. ローカルサーバで `bake.html` を開く
2. 「PCのフォントを読み込む」→ `moji-fonts.json` に載っていて Mac に入っている書体が並ぶ。焼くものに印を付ける
3. 「フォルダを選んで書き出す」→ `exhibition/HeadKana/baked` を選ぶ（無ければ作る）

焼くのは、あ〜ん 46字・濁点・半濁点・小文字・記号（`、。！？…ー` と空白）。操作画面で記号の候補を足したなら「追加の文字」に入れる。
書体に無い字は焼かずに記録に出る。その字は文字だけのページで標準の書体に戻る。
大きさの既定は 512px。それより大きく出すと少しぼける。

`baked/` は `.gitignore` に入れてあり、リポジトリには入らない。

### ラズパイへ運ぶ

```sh
rsync -a exhibition/HeadKana/baked/ pi@raspberrypi.local:~/graduation2026/exhibition/HeadKana/baked/
```

（`SourceCode` で実行。ユーザ名とホスト名はラズパイに合わせる）。USB メモリで同じ場所に置いてもよい。

操作画面は `baked/index.json` を見つけると、焼いた書体をフォントの候補に足す。
初めて開いた端末では右ダイヤルの候補にも自動で入る。前に設定を保存していた端末では「右ダイヤルに並べるフォント」で印を付ける。

### 仕組み

- `baked/index.json`：焼いた書体の一覧（名前・ウェイト）
- `baked/<書体>/glyphs.json`：字ごとの画像と大きさ。画像は字面ぴったりに切り、まわりに余白を付けている
- `baked/<書体>/<ウェイト>/<コードポイント>.png`：黒い字の PNG。文字だけのページは、これを文字色で塗る型（CSS の mask）として使うので、白黒反転でもそのまま白く出る
- 書体名は `"HeadKanaBaked-<書体>",sans-serif` として文字だけのページへ渡る。文字だけのページはこの名前を見て、画像に描き替える
