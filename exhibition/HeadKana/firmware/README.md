### StampS3 + EC11 配線

| EC11 | 1個目 | 2個目 | 用途 |
| --- | --- | --- | --- |
| S1 / A / CLK | G1 | G7 | 回転信号A |
| S2 / B / DT | G3 | G9 | 回転信号B |
| KEY / SW | G5 | G13 | 押し込みスイッチ |
| - / GND | GND | GND | 共通GND |
| + / VCC | 3V3 | 3V3 | 基板付きモジュールの電源 |

ダイヤル版v1.5は、1個目を「あ・か・さ・た・な行」（あ〜の、25文字）、2個目を「は・ま・や・ら・わ行＋ん」（は〜ん、21文字）に分割します。左右は常に独立し、それぞれの範囲で循環します。左KEYで左の文字、右KEYで右の文字を入力します。両方の位置を1つの通知で同期し、アクティブ側の切り替えはありません。同じ読取り周期で両KEYが確定した場合は左→右の順で2文字入力します。長押しはどちらも文章の末尾を1文字削除します。初期表示は「あ／は」です。BLE／USBとも対応しています。

信号ピンはG1・G3・G5の1本おきに配置し、StampS3の1.27mmピン列上で2.54mm間隔にしています。基板付きモジュールの `+` / `VCC` は3V3へ、`-` / GNDはStampS3のGNDへ接続します。5Vには接続しません。プルアップはStampS3側の内蔵プルアップを使います。回す方向が逆ならS1とS2を入れ替えます。

M5Stackの画面を450ms以内にダブルタップすると、IMU・ボタン診断画面と、ブラウザで現在選択中のかな1文字を大きく表示する画面が切り替わります。ブラウザからは選択位置（0〜45）の1バイトだけを返し、入力中の文章や文字サイズはESPへ送りません。

「動作の確認・感度を調整」内の「可動域（左右合計）」で60〜360°を10°刻みで調整できます。360°なら左右180°で46文字を選択できます。初期値120°、90°なら左右45°ずつです。「120°に戻す」で初期値に戻せます。角度設定はこのブラウザに保存され、再読み込み後も維持します。

ユーザーの動作確認に合わせ、選択文字を「あ〜ん」の46文字に限定し、変換と首かしげの操作を削除しました。辞書もサイトの配布物から除外しています。

正面から左60°〜右60°の角度で46文字を選択（約2.7°/文字）、頷き／赤ボタンで入力、強い頷きで2倍サイズ、横振り／青で削除します。少し前や横に傾いた静止姿勢で文字選択を止める条件を削除しました。左右回転は選択境界に達したサンプルで即時反映し、頷き／横振りの判定中・連続検出防止中も文字送りを続けます。頷きは正面へ戻った時に、頷き始めの選択文字を入力します。横振りは止まって160ms後に判定し、削除と認識した時だけその首振りで動いた選択を戻して1文字削除します。画面に選択位置「1 / 46」を表示します。

## 試す手順

1. サイトを再読み込みして「BLEで接続」から `M5-Kana` を選ぶ。
2. 額に装着し、正面で「正面を合わせる」を押して静止する。
3. 左右にゆっくり回して文字を選び、軽く頷いて入力。強く頷くとその文字が大きくなる。
4. かなを入れて首をかしげると漢字変換。一度正面に戻り、再びかしげると次候補。頷く／赤ボタンで候補を確定。
5. 素早く横に往復すると1文字削除。変換候補を表示中は最初に変換を取り消す。
6. 「動作の確認・感度を調整」で角度・速度・赤青ボタン状態・最近の操作を確認。首かしげ角度、強い頷き速度、横振り速度と選択方向を調整できる。

赤は入力、青は削除、青長押しは全消去、赤青同時押しは読み上げの補助操作。濁音、小書き仮名、記号を選択列に追加。上限96文字。

下線が未確定のかな。変換を確定するごとに次の言葉の入力を始める。通常コピーはプレーンテキスト。サイズ付きコピーは対応アプリ向けにHTMLもコピーする。保存やリロードを越えた文章の保持は行わない。

「接続せずに操作を試す」は画面操作用デモで、実機ジェスチャーの検証とは区別する。変換はローカル辞書で処理し、文章を外部の変換サービスに送信しない。辞書の詳細とライセンスは `site/dist/dictionary-NOTICE.txt` を参照。一般的な日本語IMEほど高度な文節分割は行わない。

## ビルド

M5Stack 3.3.9 / M5Unified 0.2.26 / M5GFX 0.2.33 / QSPI PSRAM / 16MB flash / app3M_fat9M_16MB / hardware CDC + JTAG / CDC on boot。

この端末の既存ライブラリを変更しないよう、`toolchain/` 内に指定バージョンを用意した。再ビルド:

StampS3 + EC11版:

```sh
'/Applications/Arduino IDE.app/Contents/Resources/app/lib/backend/resources/arduino-cli' compile --config-file toolchain/arduino-cli.yaml --fqbn 'm5stack:esp32:m5stack_stamp_s3:PSRAM=disabled,FlashSize=8M,USBMode=hwcdc,CDCOnBoot=cdc' --build-path build/dial-cache --output-dir build/dial HeadKanaDial
```

頭部IMU版:

```sh
'/Applications/Arduino IDE.app/Contents/Resources/app/lib/backend/resources/arduino-cli' compile --config-file toolchain/arduino-cli.yaml --fqbn 'm5stack:esp32:m5stack_cores3:PSRAM=enabled,FlashSize=16M,PartitionScheme=app3M_fat9M_16MB,USBMode=hwcdc,CDCOnBoot=cdc' --build-path build/cache --output-dir build HeadKana
```

USBポートはこの端末で確認した `/dev/cu.usbmodem101`。別の端末では再検出すること。

## 文字だけの別タブ表示（2026-11-01）

操作画面の「文字だけを別タブで表示」で `/output.html?source=...` を新しいタブへ開きます。白背景の中央に入力済み文字だけを表示。入力・削除・全消去・濁点修飾・文字ごとのフォント／ウェイト／サイズを同期し、未入力なら白紙です。操作画面は開いたまま使います。文章をストレージへ保存せず、同じオリジンのBroadcastChannelで通信します。操作タブIDのみsessionStorageへ保持し再読み込み後も表示先を維持。ローカルフォントも同じオリジンのタブ間で共有します。

古い操作画面は再読み込み後にUSB/BLEを接続し直してください。`node tests/test_text_output.cjs` で初期同期、装飾、別タブ分離、全消去を確認します。


### 未確定文字のプレビュー

ダイヤル中央の選択中文字にもフォント・サイズ・ウェイトを反映します。文字だけの別タブは入力済み文章の末尾に、現在の選択文字を同じ装飾・細い下線付きで表示。確定後は候補を重複表示せず、次に選択や装飾を変えるとプレビューを再表示。全消去直後は白紙に戻ります。ローカルフォント機能は維持しています。


### サイズスライダーの感度

GP29のサイズは12〜128pxを維持し、入力正規化値xに対して12+116×(1−(1−x)²)で拡大。25%で63px、50%で99px、100%で128pxになります。小さな操作で大きさの差を出すためのWeb側変更で、ファームウェア再書き込みは不要。


### サイズ上限300px（2026-11-01更新）

サイズ範囲を12〜300pxへ拡大。25%入力で138px、中央で228px、最大300px。式は12+288×(1−(1−x)²)。GP29=サイズ、GP28=ウェイトで独立。両方が動く件はユーザーが配線側のミスと確認したため、ファームウェア変更は行っていません。


### 実測ログと600px対応（2026-11-01）

`artifacts/slider-check/samples.csv` に652フレームを記録。サイズ側の往復ではGP29=0〜4095・GP28=4095固定、ウェイト側ではGP28=0〜4095・GP29=4095固定。どちらも全域取得でき、今回の測定で相互干渉なし。受信値はファームウェアの平滑化・デッドバンド後のADC値で抵抗値Ωそのものではありません。

サイズ範囲は12〜600pxへ拡大。式12+588×(1−(1−x)²)、中央453px・最大600px。既存の1文字ごとの装飾保持を維持。ファームウェア変更なし。


## 回転と角度固定（2026-11-02）

未確定の文字は6秒で1周し、確定を処理した時点の角度を文字ごとに保存します。フォント・サイズ・ウェイトと角度は以後の操作で変わりません。表示タブは余白なしで画面全面を使い、FullScreen API対応ブラウザではダブルクリックで全画面切り替えが可能です。LCDの表示は固定のまま、回転はWeb側の表現です。共通の回転開始時刻と周期をタブ間で渡し、表示を後から開いても同じ位相で回ります。
