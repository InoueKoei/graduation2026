# 母音子音 — 二人分担かな入力（MVP）

かな1文字を、**子音**と**母音**に割って二人で入力する。
K を打つ人と「あ」を打つ人がそろって、はじめて「か」になる。

ふたつの入力が**同時であるほどくっきり**、**ずれるほどぼやけて**出る。
相手と呼吸が合ったかどうかが、そのまま文字の像として残る。
許容できるずれは **1500ms** まで。それを超えると文字にならず捨てられる。

時間差はすべて CSV に記録される。

```
   子音担当              母音担当
  PCキーボード       RP2040 マクロパッド
       K       +           あ           →  か
       └────── 132ms ずれ ──────┘         （少しぼやける）
```

## 構成

| | 担当 | デバイス | 送るもの |
|---|---|---|---|
| 人1 | 子音 | PCキーボード | K S T N H M Y R W G Z D B P |
| 人2 | 母音 | Waveshare RP2040-Zero（4x4マトリクス） | F13–F17（= あいうえお） |

母音側が **F13–F17** という普通のキーボードに無いキーを送るので、
表示アプリは「この母音は必ずマクロパッドから来た」と判断できる。
子音担当が誤って A を押しても母音にはならない。

有線USBのみ。サーバーもWiFiも要らない。

## セットアップ

### 1. 表示アプリ

`index.html` をブラウザでそのまま開く（`file://` で動く。ビルド不要）。

```bash
open index.html
```

開いたら**一度画面をクリック**してフォーカスを与える。
外れているとステータスバーに「画面をクリックしてください」と出る。

> **全画面・最前面で使うこと。** タブが裏に回るとブラウザが `setTimeout` を1秒刻みに
> 丸めるため、1500msの締め切り判定が鈍る（ずれの実測自体は `performance.now()` なので
> 影響を受けないが、時間切れの判定が遅れる）。

### 2. マクロパッド

RP2040-Zero を挿すと `CIRCUITPY` ドライブが見えるので、`firmware/code.py` を放り込む。

```bash
cp firmware/code.py /Volumes/CIRCUITPY/code.py
```

CircuitPython と KMK は導入済み（CircuitPython 10.2.1 / `kmk/` がドライブ直下にある）。
書き込むと自動でリセットがかかり、すぐ効く。

キー配列は 4x4 の左上5つ。残り11キーは `KC.NO` で無効にしてあるので、
母音担当は**あいうえお以外を打てない**。

```
[あ][い][う][え]
[お][  ][  ][  ]
[  ][  ][  ][  ]
[  ][  ][  ][  ]
```

## 操作

| キー | |
|---|---|
| `⌘S` | ログを CSV でダウンロード |
| `BS` | 直前の1文字を消す（画面のみ。ログは残る） |
| `⌘BS` | 画面を全消し |
| `⌘L` | ログを消去（確認あり） |
| `⌘D` | テストモード切替 |

**テストモード**は、マクロパッドが無いときに PCキーボードの A I U E O を母音として
受け付ける動作確認用。ONのあいだはステータスバーに赤字で出る。
本番の記録では必ずOFFにすること（CSV の `test_mode` 列にも残る）。

## 判定のルール

先に来たほうが「相方待ち」になり、1500ms の持ち時間のあいだ待つ。
待機中は画面下の線が右から消えていく。

| 起きたこと | 結果 | ログ |
|---|---|---|
| 1500ms以内に相方が来た | かなを表示 | `成立` |
| 1500ms待っても来なかった | 何も出ない | `不成立(時間切れ)` |
| 待機中に同じ側をもう一度打った | 前の入力を捨てて打ち直し | `不成立(上書き)` |
| そろったが かな が無い組み合わせ | 何も出ない | `無効(組み合わせ)` |

`無効(組み合わせ)` は yi・ye・wi・wu・we の5つ。
**ん・っ・拗音（きゃ等）・濁点の後付けは MVP の対象外。**

## ぼかしの式

```
ずれの割合 = min(時間差 / 1500ms, 1)
ぼかし量  = ずれの割合 × 0.22em     ← 文字サイズ比なので画面サイズが変わっても同じ見え方
```

実測値（文字サイズ132pxのとき）:

| 時間差 | ぼかし | 見え方 |
|---|---|---|
| 0ms | 0.000em | くっきり |
| 150ms | 0.022em | わずかに柔らかい |
| 300ms | 0.044em | 輪郭が緩む |
| 500ms | 0.073em | ぼやけるが読める |
| 750ms | 0.110em | かなり怪しい |
| 1000ms | 0.147em | ほぼ読めない |
| 1500ms | 0.220em | 像だけ残る |

判別できるのは実質 0〜750ms あたりまで。二人が合わせにいく範囲がちょうどここに入る。
きつすぎる／緩すぎるときは `index.html` 冒頭の `MAX_BLUR_EM` を動かす。

## ログ

`⌘S` で CSV が落ちる（`boin-shiin_20260813-012700.csv`）。BOM付きなので Excel でも化けない。

| 列 | 中身 |
|---|---|
| `no` | 通し番号 |
| `wall_time` | 発生時刻（ISO8601 / UTC） |
| `result` | 成立 / 不成立(時間切れ) / 不成立(上書き) / 無効(組み合わせ) |
| `consonant` `vowel` `kana` | 打たれた子音・母音と、できたかな |
| `first` | どちらが先に来たか（子音 / 母音） |
| `gap_ms` | 時間差の絶対値 |
| `signed_gap_ms` | 符号付き時間差。**正=子音が先、負=母音が先** |
| `blur_ratio` | 0〜1 に正規化したずれ |
| `blur_em` | 実際にかけたぼかし量 |
| `test_mode` | テストモード中の記録なら 1 |

不成立・無効の行も残るので、「合わせられなかった回数」も後から数えられる。
リロードで消えないよう localStorage に控えを取っているが、**セッションごとに ⌘S で
CSV を落としてから ⌘L で消す**運用にすること。

## 調整するところ

| どこ | 何 |
|---|---|
| `index.html` の `MAX_GAP_MS` | 許容する時間差（既定 1500） |
| `index.html` の `MAX_BLUR_EM` | 最大のぼかし量（既定 0.22） |
| `index.html` の `CONSONANT_KEYS` | 子音の追加・削除 |
| `index.html` の `KANA` | かな表 |
| `firmware/code.py` の `keyboard.keymap` | 母音キーの物理配置 |

`VOWEL_KEYS`（index.html）と母音キーの定義（code.py）は**対で直す**こと。
macOS に F13–F17 を取られる場合は両方 F18–F22 などに逃がす。

## 注意

- `firmware/code.py.hatomugi-backup` は、このパッドに元々入っていたハトムギ茶マクロの
  ファームウェア。戻すときは `cp firmware/code.py.hatomugi-backup /Volumes/CIRCUITPY/code.py`。
- 4x4マトリクスにダイオードが無い場合、3キー以上の同時押しでゴーストが出る。
  このMVPは同時に1キーしか使わないので問題にならない。
