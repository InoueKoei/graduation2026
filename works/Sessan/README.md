# Sessan（空中タイピング）

手のジェスチャと表情（口形・目）だけで、キーボードに触れずにかなを入力する試み。
MediaPipe Holistic で手・顔を同時に追跡する。

## 実行方法

カメラと ES モジュールの都合で **ローカルサーバ経由**で開く（`file://` 不可）。

```sh
cd Sessan
python3 -m http.server 8000
# → http://localhost:8000/
```

## 操作

| 動作 | 割り当て |
|---|---|
| 指の本数（両手合計 1〜10） | **行**（あ／か／さ…わ行） |
| 口の形（あいうえお） | **段**（母音） |
| 同じ字を保持（約22フレーム） | その字を**確定入力** |
| 目を閉じて保持（約25フレーム） | **1字削除**（バックスペース） |
| グーを保持（約30フレーム） | 末尾に**濁点**（片手）／**半濁点**（両手） |

- ステージ右上の ⚙ で HUD（指・母音・確定/修飾メーター・目）の表示を切り替え。
- 同じくステージ右上の ◐ で **ライト / ダーク**切り替え（sumi の2モード）。
- 画面はヘッダーなしのコンパクト構成。

## 表示サイズ（iPad 縦置きで高くなりすぎない）

映像は**ネイティブ比のまま等倍**で表示する（切り抜き・余白・歪みのいずれも無し）。
そのうえで**ステージの高さに上限**を設け、**幅をその高さと比から逆算**するため、
iPad 縦置きでもカメラ表示が縦に伸びすぎない。

- 高さ上限は `style.css` の `--stage-max-h`（既定 `44vh`）で調整
- 幅は `--content-w = min(560px, 100%, var(--stage-max-h) * var(--cam-ar))`。パネルも同じ幅で揃う
- カメラ比 `--cam-ar` は初回フレームで JS（`syncFrameSize`）が実解像度から設定

実測（768×1024 の iPad 縦置き）: 16:9 カメラで 560×315、4:3 で 560×420。
縦が短い横置き（1024×768）では高さ上限が効いて 4:3 が 451×338 に収まる（比は保ったまま）。

## 記録（文字＋顔スナップ）

文字を確定するたびに、その瞬間の**カメラ全体フレーム**を縮小して下部フィルムストリップに
「文字＋顔サムネイル」として記録する。バックスペースで末尾の記録も戻り、濁点等ではラベルのみ更新。
**このセッション内の画面表示のみ**（ファイル/DB への保存はしない）。設定は `config.js` の `SNAPSHOT`。

## UI（sumi デザインシステム）

見た目は `sumi` デザインシステム（`CLdev/sumi-ui`）の墨基調トークンに準拠。
`sumi-tokens.css`（`CLdev/sumi-ui/src/styles/tokens.css` の同梱コピー）を読み込み、
色はすべて `--color-*` セマンティックトークン参照。書体は ZEN Interface（未読込時は system-ui）。
※ sumi 側を更新したら `sumi-tokens.css` を再コピーして同期すること。

## ファイル構成

```
sumi-tokens.css … sumi デザイントークン（同梱コピー・light/dark）
style.css       … 画面スタイル（sumi トークン参照。sumi-tokens.css の後に読み込む）
config.js       … 五十音表・濁点表・しきい値・口形/目のターゲット・Holistic・SNAPSHOT 設定
typing-core.js  … 指数え・口形/目の判定・HoldGate（保持確定）※MediaPipe 非依存の純粋関数
script.js       … 本体（Holistic・カメラ・HUD・状態機械・スナップショット記録・テーマ切替）
```

## メモ

- 口形ターゲット（`VOWEL_TARGETS`）と目の開閉（`EYE_TARGETS`）は**手調整済みの値**。
  照明や個人差でうまく判定しないときはここを微調整する。
- MediaPipe Holistic は旧 solution 系 API。挙動維持のため意図的にそのまま採用している。
- `_legacy_backup_2026-07-16/` に旧コードを退避（不要なら削除可）。
